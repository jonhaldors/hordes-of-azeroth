## 计划中的改动

- **内容覆盖层**：自定义法术/光环/物品不在客户端安装的 DBC 里。服务端在 addon ready 和切语言时通过类型化协议下发已本地化的光环目录，客户端通过 `SpellCatalog::set_overlay`（`hoa_aura.rs`）安装并覆盖 DBC 查询结果。完整的内容包生成仍属后续工作。
- **语言包**：客户端自己的界面文本（选项、菜单、Glue、错误提示）从语言包读取，语言由服务端在登录时下发，不再由安装数据的语言决定。
- **缓存键**：WDB/模板缓存按 `(locale, content version)` 分桶；语言或内容更新时自动失效，避免切换语言后仍显示旧名字。账号语言已折进 WDB 头部标签，内容版本等客户端内容包落地后再加。
- **原生能力**：buff、等级、施法、冷却直接使用客户端原有系统；HoA 状态不再通过自定义聊天行同步。
- **内核保留**：网络、移动、战斗、渲染、Lua/FrameXML 引擎保持 benilla 的实现，只改 HoA 接入点和性能热点。

## 数据来源
